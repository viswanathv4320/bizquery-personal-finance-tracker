## Project Summary

Hello! BizQuery is a web-based personal finance tracker that allows users to record expenses and income, categorize transactions, set budgets, and visualize trends. The system will use an SQL database to store user accounts, transaction history, categories, and budgeting data. The goal of the project is to provide users with clear insight into their spending habits. This will allow users to make informed decisions through visualizations and budget monitoring.
